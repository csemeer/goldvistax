## 1. Audit Classification Taxonomy

- **IMPLEMENTED**: Code exists, is wired through UI/API/service, and executes functional behavior with test coverage.
- **PARTIAL**: Basic functionality exists, but lacks certain production features (e.g. mock persistence, limited edge cases).
- **STUBBED_MOCK**: Interface exists with hardcoded/simulated responses or mock data structures.
- **CONFIGURED_NOT_EXERCISED**: Configuration keys or connectors defined in code but lack external live production credentials.
- **PRESENT_BUT_BROKEN**: Code exists in codebase but throws runtime/build errors under specific edge cases.
- **REPORTED_ONLY**: Represented in completion reports or vision blueprints but absent in inspected codebase.
- **NOT_FOUND_IN_SCOPE**: Feature requested in proposal catalogue not found in current repository.
- **NOT_VERIFIED**: Code present but requires external vendor entitlements, legal licenses, or production execution credentials to verify.
